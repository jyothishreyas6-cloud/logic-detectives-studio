FOR GROWN-UPS
Learning goal: each digit's place shows its size (thousands, hundreds, tens and ones), and zero holds a place when there are none.
Curriculum link: NSW Mathematics K-10 Syllabus (2022), Stage 2 (Years 3 and 4), Representing numbers using place value, MA2-RN-01: "applies an understanding of place value and the role of zero to represent numbers". https://curriculum.nsw.edu.au/learning-areas/mathematics/mathematics-k-10-2022/content/stage-2/fa1dbb9271
Ask your child after watching: "Why can't we just leave the zero out of 3052?"
Try it together: build a four-digit number with coins, blocks or drawings, with nothing in one place, and write it down with a zero.

"Hey! That's not fair! The cricket box is locked!" Can your child crack the four-digit code?

WHAT YOUR CHILD WILL LEARN
- Digits are the numbers zero to nine.
- Place value: a digit's place shows its size (thousands, hundreds, tens, ones).
- Zero holds a place when there are none, so 3052 is not the same as 352.

WHAT HAPPENS IN THIS CASE
The cricket box at the park has a four-dial lock. Mabel left a clue made of number blocks: three big thousand cubes, five ten sticks and two little ones. Otto reads "three, five, two!", but the lock has four dials. Detective Bramble says, "Let's not guess. Let's test." Your child is asked to find the hundreds, then picks between two codes with five quiet seconds to think. The blocks go onto a place value mat: there are no hundreds, so we write zero. The code is 3052, and counting the blocks proves it: three thousand, three thousand and fifty, three thousand and fifty-two. Case solved! And out hops a surprise: a real cricket. At the end, your child is invited to say the rule out loud: "Zero holds the place."

KEY WORDS
digit, place value, thousands, hundreds, tens, ones, zero, place value mat, number blocks

TRY IT AT HOME
Make a secret four-digit code with a zero in it (like 4071 or 2905). Build it with coins, pasta pieces or drawings of blocks, leaving one place empty, and ask your child to write the code. Then swap: they make a code for you. At the canteen or shops, count $1 coins in tens to see that ten ones make one ten.
